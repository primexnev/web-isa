# Portfolio – Nevzat Onay

Simple portfolio website for the HSLU course WEB_ISA.

## Built with
- HTML
- Tailwind CSS (CDN)
- One own CSS file (`css/style.css`)

## Folder structure
```
portfolio/
├── index.html      → the page (content + Tailwind classes)
├── css/
│   └── style.css   → own CSS rules
├── images/         → profile and project images (public domain or own)
└── README.md
```

## Run
Open `index.html` in a browser. No installation needed.
