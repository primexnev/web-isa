# Portfolio – Nevzat Onay

Simple portfolio website for the HSLU course WEB_ISA.

## Built with
- HTML
- Tailwind CSS (CDN)
- One own CSS file (`css/style.css`)

## Folder structure
```
web-isa/
├── index.html      → the home page (content + Tailwind classes)
├── projects/       → one page per project
├── css/
│   └── style.css   → own CSS rules
├── images/         → profile and project images (own work)
└── README.md
```

## Run
Open `index.html` in a browser. No installation needed.
